## 主なプロジェクト

### マルチチャネル Agent プラットフォーム、2026 年 4 月〜現在

持続的なマルチチャネルアシスタント（Web + Discord）向けのクライアント向けプラットフォーム。

- 各 agent run を**ステートフル・中断可能・再開可能**な持続ストリームとしてモデル化：クライアントは切断・再接続し、実行途中から進捗を失わず再開できる——ネストしたチャット条件ではない。
- Mastra と AI SDK 上に workflow、memory、scheduling、workspace のプリミティブを構築：pause/resume、retries、サンドボックスツール、skills。
- エンドツーエンドの RAG（ingest、chunk、Pinecone query/rerank）をリリースし、スコア付き evals（golden prompts + LLM-as-judge）でリリースをゲート。
- **Docker 化**した Hono + Better Auth を **ECS Fargate** で運用。コアデータは Postgres、ファイルは S3。ClickHouse で run/tool traces とコスト／レイテンシ——問題の切り分けは UI、API、agent コンポーネントにまたがる。
- 組み合わせ可能なチャット、ツール呼び出し、多段階クライアントフロー、およびワークスペースファイルを prompts に付ける TipTap @mention ファイルタグ付けコンポーネントをリリース。
