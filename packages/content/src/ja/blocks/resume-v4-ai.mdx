## 主なプロジェクト

### マルチチャネル Agent プラットフォーム、2026 年 4 月〜現在

持続的アシスタント（Web + Discord）向けのクライアント向けプラットフォーム。本番の信頼性と品質管理を備える。

- request/response チャットではなく持続ストリーミングを選び、長い tool loops が切断後も生き残るようにした。クライアントは実行途中から進捗を失わず再開できる。
- Mastra と AI SDK 上に workflow、memory、scheduling、workspace のプリミティブを構築：pause/resume、retries、ファイル保存、サンドボックスツール、skills。
- エンドツーエンドの RAG をリリース：ingest/parse、chunking、Pinecone retrieval（query/rerank、必要に応じて graph query）。Retrieval は**組織スコープ**（namespace = organization）であり、モデルは別テナントを検索できない。
- ClickHouse で run/tool traces とコスト／レイテンシ指標を追加。prompt や tool 変更後はスコア付き evals でリリースをゲート——問題の切り分けは UI、API、agent runs にまたがる。
- **Docker 化**した Hono + Better Auth を **ECS Fargate** で運用。コアデータは Postgres、ファイルは S3——agent の状態と成果物が単一リクエストを超えて残るようにした。
- TipTap @mention ファイルタグ付けコンポーネントをリリースし、ワークスペースファイルが貼り付けテキストではなく第一級のコンテキストとして prompts に入るようにした。
