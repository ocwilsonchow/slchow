5 年の経験を持つフルスタックソフトウェアエンジニア。**Figma** から **React** / **React Native**、型付き API、**AWS** デプロイまでの納品を一貫して担当——ゼロイチの立ち上げと **15+** アプリの多年にわたる進化を含む。クリティカルパスの読み込み時間を最大 **80%**、検索レイテンシを **90%** 削減。現在は持続的で中断可能な workflows、memory、**RAG**、scorers、evals を備えたマルチチャネル agent プラットフォームを主導。日常開発に **Cursor** / AI 支援ツールを使用。**AWS Solutions Architect Associate**。

スタック：**Next.js**、**React Native**、**Hono**、**Drizzle**、OpenAPI / tRPC / GraphQL、**Better Auth**、**Mastra**、**AI SDK**、**Langchain**、**Pinecone**、Postgres、**SST**、AWS；headless CMS と検索は **Strapi**、**Sanity**、**Meilisearch**。
