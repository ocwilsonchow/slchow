5 年の経験を持つフルスタックプロダクトエンジニア。**Figma** デザインから **React** / **React Native**、型付き API、**AWS** デプロイまでの納品を一貫して担当。15 以上の本番 Web／モバイルアプリをリリースし、クリティカルパスの読み込み時間を最大 **80%**、検索レイテンシを **90%** 削減。現在は持続的ワークフロー、**RAG**、**MCP** servers、evals を備えたマルチチャネル agent プラットフォームを主導。**AWS Solutions Architect Associate**。

強み：エンドツーエンドのプロダクトオーナーシップ · React · フロントエンドエンジニアリング · 本番 AI agents · デザインシステム。

スタック：**Next.js**、**React Native**、**Hono**、**Drizzle**、OpenAPI / tRPC / GraphQL、**Mastra**、**AI SDK**、**Langchain**、Postgres、**SST**、Terraform、AWS、Vercel；headless CMS と検索は **Strapi**、**Sanity**、**Meilisearch**。
