## 概要

5 年の経験を持つソフトウェア開発者。**Figma** デザインと **React** 開発から、バックエンドおよびクラウドデプロイまでのフルスタック納品を担当。15 以上の本番アプリをリリース。**AWS Solutions Architect Associate** 認定取得。

デザインシステム、高度なアニメーション、高性能な **Next.js** / **React Native** アプリを構築。バックエンドは **Hono**、**Drizzle**、**OpenAPI**、**tRPC**、**GraphQL**。Headless CMS と検索は **Strapi**、**Sanity**、**Meilisearch**。

本番向け **AI agents**、**RAGs**、**MCP servers** の経験あり。**AI SDK**、**Langchain**、**Mastra** を使用。

**SST**、**Terraform**、**AWS**、**Vercel** によるクラウドインフラのデプロイと運用に習熟。

## 主なプロジェクト

### _Agentic Platform、2026 年 4 月〜現在_

- **マルチチャネル** agent プラットフォーム（web + Discord）を主導。持続的ストリーミングにより、クライアントは実行中に切断しても進捗を失わず再開できる。
- **Mastra** と **AI SDK** 上に workflow、memory、scheduling、workspace のプリミティブを構築：pause/resume、retries、ファイル保存、サンドボックスツール、skills。
- エンドツーエンドの **RAG** をリリース：ingest/parse、chunking、**Pinecone** retrieval（query/rerank、必要に応じて graph query）。
- **Hono** + **Better Auth** バックエンドを **ECS** で運用。コアデータは **Postgres**、ファイルは **S3**。
- **ClickHouse** で run/tool traces とコスト／レイテンシ指標を観測。golden prompts + LLM-as-judge によるスコア付き eval suites で品質回帰を検出。
- ワークスペースファイルを agent prompts に添付するための **TipTap** **@mention** ファイルタグ付けコンポーネントを設計・リリース。

---

### _Full Stack Marketing Site、2025 年 11 月_

- **Next.js** コンテンツサイトを **Strapi** バックエンドと **Meilisearch** で構築。**LCP < 0.5s**、**CLS < 0.1**、PageSpeed Insights **>90** を達成。
- ハイブリッド **ISR**：主要ページと最新 100 記事をビルド時に事前レンダリング。残りはオンデマンドのフォールバック生成。
- Strapi コンテンツ **webhooks** による **tag-based revalidation** で、フルリビルドなしに公開を反映。
- 対話 UI は **TanStack Query** のサーバー prefetch/hydration。フォームは **TanStack Form**、**Zod**、Query mutations。
- **Turborepo** を **SST** 経由で **AWS ECS** にデプロイ。**API Gateway** 経由でルーティング。メディアは **S3**。
- **アクセシビリティ**：セマンティックな landmarks／見出し、キーボード操作可能なナビとフォーム、可視フォーカス、CMS メディアの意味のある alt text。**Lighthouse** と **axe** で a11y テスト。
- **SEO**：Strapi 由来の metadata/OG tags、canonical URLs、sitemap + `robots.txt`、Article JSON-LD 構造化データでコンテンツページをインデックス可能に。
- **AI SDK** による生成 AI コンテンツ作成用の **カスタム Strapi plugin** を構築。

### _React Native App、2024 年 4 月_

- ケータリングブランド会員アプリ（デジタルカード、ポイント、オファー）の **Figma** デザインと **React Native** フロントエンドを主導。
- **OpenAPI**/Swagger から型付き REST クライアントをバックエンドと統合。iOS & Android を App Store と Play Store にリリース。
- プロモとマイルストーン向けのプッシュ＋ディープリンクキャンペーン。
- ローンチ後 **>99.5%** の crash-free sessions を維持。**Sentry** で監視。
- メニュー／履歴リストのジャンクを **FlashList**（recycling、batch/window 調整）で削減。ScrollView 行マップの代わりに使用。
- **react-native-screens** freeze と遅延画面マウントで非アクティブタブを軽量化。**Reanimated** はネイティブスレッド遷移に限定。
- フィードでリモート画像をキャッシュし、長いリストでフル解像度アセットを回避。
