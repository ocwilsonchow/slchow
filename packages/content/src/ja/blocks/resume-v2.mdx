## 主なプロジェクト

### マルチチャネル Agent プラットフォーム、2026 年 4 月〜現在

持続的なマルチチャネルアシスタント（Web + Discord）向けのクライアント向け agent プラットフォーム。本番の信頼性と品質管理を備える。

- 持続的ストリーミングを主導し、クライアントが実行中に切断しても進捗を失わず再開できるようにした。
- Mastra と AI SDK 上に workflow、memory、scheduling、workspace のプリミティブを構築：pause/resume、retries、ファイル保存、サンドボックスツール、skills。
- エンドツーエンドの RAG をリリース：ingest/parse、chunking、Pinecone による retrieval（query/rerank、必要に応じて graph query）。
- Hono + Better Auth を ECS で運用。コアデータは Postgres、ファイルは S3。
- ClickHouse で run/tool traces とコスト／レイテンシ指標を追加。golden prompts + LLM-as-judge によるスコア付き eval suites でリリース前の品質回帰を検出。
- ワークスペースファイルを agent prompts に添付するための TipTap **@mention** ファイルタグ付けコンポーネントをリリース。

---

### 高性能マーケティングサイト、2025 年 11 月

コンテンツ＋検索型マーケティングサイトのリードエンジニア — パフォーマンス、CMS、公開ワークフローをエンドツーエンドで担当。

- Next.js + Strapi + Meilisearch のコンテンツサイトで **LCP &lt; 0.5s**、**CLS &lt; 0.1**、PageSpeed Insights **>90** を達成。
- ハイブリッド ISR：主要ページと最新 100 記事をビルド時に事前レンダリング、残りはオンデマンド。Strapi webhooks による tag-based revalidation で、フルリビルドなしに公開を反映。
- AI SDK を使った生成 AI コンテンツ作成用のカスタム Strapi plugin を構築。
- アクセシビリティと SEO を納品基準に：セマンティック構造、キーボード対応のナビ／フォーム、Lighthouse + axe チェック；CMS 由来の metadata/OG、canonicals、sitemap、robots.txt、Article JSON-LD。
- Turborepo を SST 経由で AWS ECS にデプロイ。API Gateway と S3 メディア。対話 UI は TanStack Query の prefetch/hydration と TanStack Form + Zod mutations。

---

### React Native 会員プラットフォーム、2024 年 4 月

- ケータリングブランドの会員アプリ（デジタルカード、ポイント、オファー）の Figma デザインとフロントエンド開発を主導。iOS / Android を App Store と Play Store にリリース。
- バックエンド保守も担当：Express API と Next.js 管理画面。
- OpenAPI/Swagger から型付き REST クライアントを統合。Firebase Cloud Messaging でプッシュ通知とディープリンクキャンペーン（プロモとマイルストーン）。
- ローンチ後 **>99.5%** の crash-free sessions を維持（Sentry）。
- FlashList でリストのジャンクを削減。react-native-screens freeze と遅延マウントで非アクティブタブを軽量化。Reanimated はネイティブスレッド遷移に限定。
- リモート画像をキャッシュし、長いリストでフル解像度アセットを避けてフィードの画像読み込みを短縮。
