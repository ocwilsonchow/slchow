**Mastra** 與 **LangChain Deep Agents** 都支援 agents、tools、memory 與 streaming。真正的差異，在於各自把邊界劃在哪裡。

Mastra 是一套整合式 TypeScript framework，面向 AI applications。Agents、workflows、memory、RAG、evaluation、observability、local Studio、server，以及 deployment adapters，共用同一套 programming model。

Deep Agents 是建立在 **LangChain** 與 **LangGraph** 之上、帶有明確意見的 autonomous-agent harness。它提供 files、context offloading、subagents、memory 與 middleware，然後依賴 LangChain 做 retrieval、LangGraph 做 explicit workflows 與 persistence，以及 LangSmith 做 operations。

- 當 agents 是更廣泛應用裡、deterministic workflows 的一部分時，選 **Mastra**。
- 當你做的是圍繞 files、subagents 與 context management 的 autonomous research、coding 或 operations agents 時，選 **Deep Agents**。
- 在投入任何一邊之前，先驗證 **durability 與 deployment model**。

<br />

## 1. The Core Difference

Deep Agents 不是用來取代 LangChain。`deepagents` package 把 LangChain 與 LangGraph 組裝成預建的 agent harness。

- Virtual filesystem、automatic context summarization、subagent delegation、file-based skills 與 memory，以及用於 retries、approvals 與 guardrails 的 middleware。
- Mastra 從更寬的 application boundary 起步。它的 `Agent` 只是眾多 primitives 之一，與 tools、workflows、storage、vector stores、scorers、API routes 與 deployment configuration 並列。

| Area                    | Mastra                                    | Deep Agents                        |
| ----------------------- | ----------------------------------------- | ---------------------------------- |
| Primary abstraction     | AI application framework                  | Autonomous agent harness           |
| Deterministic workflows | First-class                               | Built with LangGraph               |
| Multi-agent model       | Agents and workflows exposed as tools     | Supervisor delegates to subagents  |
| RAG                     | Mastra packages and integrations          | LangChain retrieval ecosystem      |
| Persistence             | Mastra memory and durable execution       | LangGraph checkpointers and stores |
| File context            | Workspaces, skills, and file-based agents | Foundational virtual filesystem    |
| Managed runtime         | Mastra Platform                           | Managed Deep Agents or LangSmith   |

Mastra 在 package 層面更廣。若把周邊 LangChain ecosystem 算進去，Deep Agents 的覆蓋面就會變得更廣。

## 2. Building an Agent

兩邊都支援 TypeScript、Zod-validated tools，以及 model streaming。差異不在 type safety。

<br />

```ts title="src/mastra/agents/support-agent.ts"
import { Agent } from "@mastra/core/agent"
import { createTool } from "@mastra/core/tools"
import { z } from "zod"

const searchDocs = createTool({
  id: "search-docs",
  description: "Search product documentation",
  inputSchema: z.object({ query: z.string() }),
  execute: async ({ query }) => searchProductDocs(query),
})

export const supportAgent = new Agent({
  id: "support-agent",
  name: "Support Agent",
  instructions: "Answer from the documentation and cite the evidence.",
  model: process.env.AGENT_MODEL!,
  tools: { searchDocs },
})
```

<br />

```ts
import { createDeepAgent } from "deepagents"
import { tool } from "langchain"
import { z } from "zod"

const searchDocs = tool(({ query }) => searchProductDocs(query), {
  name: "search_docs",
  description: "Search product documentation",
  schema: z.object({ query: z.string() }),
})

export const supportAgent = createDeepAgent({
  model: process.env.AGENT_MODEL!,
  systemPrompt: "Answer from the documentation and cite the evidence.",
  tools: [searchDocs],
})
```

<br />

- Mastra 的 registries 與 shared resource model 感覺像 application framework；Deep Agents 感覺像在配置一套 graph-backed runtime。
- Mastra 的 local server 與 Studio 暴露 agents、workflows、traces、datasets 與 scorers。
- 一套完整的 Deep Agents application 通常橫跨 `Deep Agents → LangChain → LangGraph → LangSmith`（harness、tools、state、operations）。
- Mastra 在它打算走的路上減少概念跳躍。Deep Agents 在需要更多控制時，提供直接逃進 LangGraph 的 hatches。

<br />

## 3. Deterministic Workflows

Agent 讓 model 選擇下一步發生什麼。**Workflow** 則把重要 transitions 寫進程式碼裡。

- 當序列是一條 business rule 時用 workflow：validate input、collect data、request approval、publish，並記錄結果。
- Mastra workflows 是 first-class、typed primitives。Steps 宣告 input 與 output schemas，可以順序、並行、經 branches，或在 loops 裡組合。
- Steps 可以為 human approval 而 suspend，再用 typed payload resume。Model 在 step **裡面** 仍保持靈活，但不控制整個過程。

<br />

```ts
const articleWorkflow = createWorkflow({
  id: "article-workflow",
  inputSchema: z.object({ topic: z.string() }),
  outputSchema: z.object({ article: z.string() }),
})
  .then(research)
  .then(write)
  .then(approve)
  .commit()
```

<br />

- Deep Agents 的 subagent delegation 是 model-directed，不是 deterministic workflow。要 explicit state 與 transitions，就跟 LangGraph 組合：nodes、edges、checkpoints、interrupts、streaming、subgraphs。
- 對 workflow-heavy products，Mastra 通常是更短的路。對已經在用 LangGraph 的團隊，Deep Agent 可以是自訂 state machine 裡一個有能力的 node。

**Failure：** 把 subagent delegation 當成 business-rule DAG 的替代。LangGraph 的成本是自己管理 graph state、reducers、nodes 與 transitions。

<br />

## 4. Durability and Memory

「Memory」常常把好幾項分開的需求藏在一起：

1. **Message history** 讓 conversation 保持連貫。
2. **Working memory** 存放 preferences、goals 或 task state。
3. **Long-term memory** 跨 conversations 共享知識。
4. **Durable execution** 恢復被打斷的工作。
5. **Resumable streaming** 讓 client 重新接到正在跑的 task。

Persisted messages 並不會讓任意程式碼變成 durable。

<br />

```ts
const memory = new Memory({
  storage: new PostgresStore({
    id: "support-memory",
    connectionString: process.env.DATABASE_URL!,
  }),
  options: {
    lastMessages: 20,
    workingMemory: { enabled: true },
  },
})

await agent.stream("Continue the migration plan", {
  memory: {
    thread: "conversation-42",
    resource: "user-123",
  },
})
```

<br />

- Mastra 的 `Memory` 把一次 conversation **thread** 關聯到一個 user 或 tenant **resource**。它可以組合 recent messages、semantic recall、structured working memory，以及 observational memory。
- Durable-agent APIs 讓 clients 用 run ID 重新接到長 streams。必須在 process crash 後活下來的工作，屬於 durable 或 workflow-backed execution。
- LangGraph **checkpointer** 持久化 thread-scoped graph state、interrupts 與 resume points。LangGraph **store** 保存跨 threads 共享的資料。
- Deep Agents 把 long-term memory 表示成 files。`StateBackend` 把 scratch files 留在 thread state；`StoreBackend` 可以把 `/memories/` 與 `/skills/` 這類 paths 跨 threads 持久化。

**Failure：** 讓 model 自己挑 identifiers 與 namespaces。它們必須來自 authenticated context。Durable memory 仍然需要 retention、correction 與 deletion policies。

## 5. RAG

一套 production RAG system 有分開的 ingestion 與 query paths：

```text
ingestion → load → chunk → embed → index
query     → retrieve → filter/rerank → answer with citations
```

- Ingestion 不該在每次 agent request 時跑。一次成功的 vector lookup 並不能證明答案是 grounded。
- Mastra 提供 document chunking、經 AI SDK model interface 的 embedding support、vector-store integrations，以及可以直接掛到 agent 上的 vector query tool。
- Dynamic vector-store resolution 特別適合從 authenticated request context 選出某個 tenant 的 index。
- Deep Agents 使用 LangChain loaders、text splitters、embeddings、retrievers 與 vector stores。Ecosystem 廣度對 specialized document formats 或 retrieval strategies 很重要。
- Deep Agents 可以把 retrieved content 寫進 backend 並回傳 file paths，讓 agent 只檢查相關 sections，而不是把每個 token 都放進主 conversation。

無論走哪條路，都評估 retrieval recall 與 precision、answer groundedness、citation correctness，以及 end-to-end answer quality。

## 6. Files、Subagents 與 Sandboxes

Deep Agents 把 files 與 delegation 放在中心。Supervisor 可以把工作送給帶 isolated context 的 subagents，讓每個 specialist 做很多次 tool calls，再回傳一份緊湊的結果。

- `StateBackend` 儲存 thread-scoped virtual files。`FilesystemBackend` 暴露 host directory。`LocalShellBackend` 加上 host shell access。Provider-backed sandboxes 在遠端隔離 files 與 processes。
- Mastra 可以把 agents 與 workflows 暴露給 routing agent，並附上包含 filesystem 與可選 sandbox 的 `Workspace`。這適合 file access 只是眾多能力之一的 applications。
- Workspace path 不是 security boundary。無論哪個 framework，local shell execution 只適合 trusted development。

Production execution 需要一份全新或正確 namespaced 的 sandbox、CPU / memory / disk / time limits、受控的 network egress、明確的 file-transfer rules，以及範圍很窄的 credentials。

**Failure：** 把 isolation 當成完整防禦。它保護 host；它本身並不能阻止 prompt injection、secret exfiltration、runaway cost，或 cross-user leakage。

## 7. Observability、Evaluation 與 Safety

營運一個 agent 需要最終答案背後的路徑：model calls、tools、retrieval、subagents、workflow transitions、retries、latency、token usage、cost 與 errors。

- Mastra 為自己的 primitives 做 instrumentation，並把 traces export 到 Studio、Mastra Platform，或 OpenTelemetry backends。它也在同一套 framework model 裡包含 scorers、datasets 與 experiments。
- Deep Agents 繼承 LangChain 與 LangGraph tracing。LangSmith 加上 dashboards、alerts、datasets、offline 與 online evaluators、annotation queues，以及 deployment monitoring。
- Mastra 的 observability 感覺像 framework primitive。LangSmith 是更廣的 operations product。兩邊都可以參與既有的 OpenTelemetry pipeline。

在五個層級測試：

1. 不帶 model calls 的 tool contracts
2. 帶受控 responses 的 workflows 或 graphs
3. 針對 quality 與 groundedness 的 dataset evaluations
4. 針對 performance 與 failure paths 的 traces
5. 針對 streaming、persistence、authentication 與 limits 的 deployed behavior

兩邊都可以透過 suspended workflow steps、tool approval，或 LangGraph interrupts 做 human approval。Approval 不能取代 runtime isolation。Agent traces 可能包含 user messages、retrieved documents、tool arguments 與 generated code——套用與應用資料相同的 access controls、redaction、retention 與 deletion rules。

## 8. Deployment

第一個 agent demo 很容易。Production 需要 durable state、background execution、authentication、secrets、observability，以及能在真實基礎設施上活下來的 streaming。

- Mastra 最整合的路徑是 Mastra Platform（`mastra deploy`）。它也可以 build 一個 Node server，或瞄準 Cloudflare 這類 platforms。Portability 仍取決於 state：local SQLite files、vectors、memory 與 workflow data 必須換成與 runtime 相容的 stores。
- Deep Agents 有三條主要路徑：**Managed Deep Agents**（先驗證可用性）、**LangSmith Deployment**（persistent state、background execution、authentication hooks、webhooks、cron、tracing、Agent Protocol APIs），以及用 Agent Streaming Protocol 在 Next.js 或 Cloudflare 上的 **application-hosted** deployment。

Application hosting 把更多責任轉給團隊：durable checkpointer 與 store、authenticate 並 authorize 每一個 thread、隔離 tenant namespaces、處理 host timeouts 與 background work，以及把 code execution sandbox 離開 web server。

| Requirement                 | Mastra                   | Deep Agents                                       |
| --------------------------- | ------------------------ | ------------------------------------------------- |
| Simplest hosted path        | Mastra Platform          | Managed Deep Agents                               |
| Established managed runtime | Mastra Platform          | LangSmith Deployment                              |
| Custom hosting              | Built server or adapter  | Agent Protocol routes or Agent Server             |
| Self-hosted durability      | Mastra storage providers | LangGraph checkpointer, store, and infrastructure |
| Enterprise topology         | Platform-dependent       | Cloud, hybrid, or self-hosted LangSmith           |

對 greenfield TypeScript 團隊來說，Mastra 的整合路徑更乾淨。若團隊已投入 LangChain，或需要 hybrid infrastructure，LangSmith 提供更多 runtime topologies。

## How to Choose

  <AccordionItem value="mastra">
    <AccordionTrigger>Choose Mastra when</AccordionTrigger>

      - Agents 是 deterministic business workflows 的一部分
      - 團隊想要一套 TypeScript model 同時涵蓋 tools、memory、RAG、evaluation 與 deployment
      - 透過 Studio 做 local inspection 很重要
      - 盡快走到 hosted application 很關鍵

    </AccordionContent>
  </AccordionItem>
  <AccordionItem value="deep-agents">
    <AccordionTrigger>Choose Deep Agents when</AccordionTrigger>
    <AccordionContent>

      - 主要任務是 open-ended research、coding、analysis 或 operations
      - Subagent delegation 與 context isolation 是核心
      - Agent 需要 files、skills、memory files 或 sandboxed execution
      - 團隊已經使用 LangChain、LangGraph 或 LangSmith
      - Graph state、middleware、persistence 或 runtime topology 需要深度定製

    </AccordionContent>
  </AccordionItem>
</Accordion>

<br />

| Need                            | Default                                         |
| ------------------------------- | ----------------------------------------------- |
| Deterministic workflows         | Mastra, unless the team already knows LangGraph |
| Conventional application memory | Mastra                                          |
| Filesystem-native memory        | Deep Agents                                     |
| Straightforward RAG             | Mastra                                          |
| Specialized retrieval           | Deep Agents with LangChain                      |
| Coding or research agent        | Deep Agents                                     |
| Managed operations              | Deep Agents with LangSmith                      |
| Existing OpenTelemetry pipeline | Either                                          |

沒有萬能贏家。Mastra 優化的是 **AI application**。Deep Agents 優化的是 **autonomous agent harness**，並把它接到更廣的 LangChain stack。

在選定之前，先 prototype 最難的 production requirement：approval workflows 的 suspend 與 resume、重新接到 long-running research、在真實 documents 上測量 RAG，以及為 code execution 驗證 sandbox 與 credential boundaries。
