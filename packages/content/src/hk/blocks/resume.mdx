## 精選專案

### _Multi-channel Durable Agent，2026 年 4 月至今_

- 主導 **multi-channel** agent 平台（web + Discord），支援 durable streaming，客戶可在 agent 執行中斷線並於中途重連繼續。
- 使用 **Mastra** 與 **AI SDK** 打造 workflow、memory、scheduling 與 workspace 原語——支援 pause／resume、retries、檔案儲存、沙盒工具與 skills。
- 端到端交付 RAG：ingest／parse、chunking、**Pinecone** retrieval（含 query／rerank，以及需要時的 graph query）。
- 後端為 **Hono** + **Better Auth**，部署於 **ECS**；核心資料使用 **Postgres**，檔案系統使用 **S3**。
- 打造 agent 可觀測性與評估：在 **ClickHouse** 記錄 run／tool traces 與成本／延遲指標，並以 scored eval suites（golden prompts + LLM-as-judge）捕捉品質回退。
- 使用 **TipTap** 設計並交付自訂 **@mention** 檔案標記元件，用於 agent 提示輸入。

---

### _Incremental Static Regeneration Next.js Site，2025 年 11 月_

- 打造 **Next.js** 內容網站，後端為 **Strapi**、搜尋為 **Meilisearch**，達到 **LCP < 0.5s**、**CLS < 0.1**，PageSpeed Insights **>90**。
- 混合式 **ISR**：主要頁面與最新 100 篇文章於建置時預渲染；其餘頁面按需以 fallback 生成。
- 透過 Strapi 內容 webhook 進行 **tag-based revalidation**，發布後可更新線上頁面而無需完整重建。
- 互動 UI 使用 **TanStack Query** 伺服器端 prefetch／hydration；表單以 **TanStack Form**、**Zod** 與 Query mutations 處理。
- **Turborepo** 透過 **SST** 部署至 **AWS ECS**，經 **API Gateway** 路由；媒體存放於 **S3**。
- **無障礙（Accessibility）**：語意化 landmarks／標題、鍵盤可操作的導覽與表單、可見 focus，以及 CMS 媒體的有意義 alt text。
- **SEO**：來自 Strapi 的 metadata／OG tags、canonical URLs、sitemap + `robots.txt`，以及 Article JSON-LD 結構化資料，提升內容頁可索引性。
