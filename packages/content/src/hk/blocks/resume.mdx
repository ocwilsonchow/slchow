## 精選專案

### 1. _Durable Agent，2026 年 1 月至今_

- 主導設計並開發具備 RAG 與聊天機器人功能的多智能體平台
- 使用 Mastra 作為 agent 框架，AI SDK 負責前端，Hono、Drizzle、Better Auth 負責後端
