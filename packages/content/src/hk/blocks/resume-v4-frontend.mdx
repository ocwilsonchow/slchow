### 高效能編輯平台，2025 年 11 月

- 將鍵盤可操作的導覽與表單錯誤、語意化結構，以及 Lighthouse + axe 檢查設為上線門檻——而非上線後補做。
- 將互動狀態與頁面資料分開：**XState** + **TanStack Form**／**Zod** 管多步流程，locale 放在路由（文案、日期、數字），內容走混合 ISR。

### React Native 會員平台，2024 年 4 月上線

- 負責會員流程（電子會員卡、積分、優惠），從 Figma 做到 iOS／Android App Store 與 Play Store 上架；同時負責 **Next.js** 管理後台。
- 工作階段風險：refresh tokens 存於 **SecureStore**／Keychain，Face ID／指紋解鎖；以 **OpenAPI** 產生型別安全 **REST** 客戶端。
- 上線後維持 **99%** crash-free sessions，以 **Sentry** 診斷崩潰、裝置相容性與 API 瓶頸。
- 改善動態列表捲動卡頓：**Sentry** 顯示長列表與全解析度圖片卡住 JS thread；改用 **FlashList** + 列 memoization，快取／縮小動態列表圖片，並以 **Reanimated**／**Moti** 在原生執行緒做轉場。凍結非作用中分頁並延遲掛載（那些分頁會較晚繪製）。穩定 **60fps**（實驗室數據，RN Perf Monitor）。
- 以 Firebase Cloud Messaging deep links，把促銷與會員里程碑通知導向對應畫面。

跨客戶產品：

- 負責共用 **Radix**／**Tailwind**／**shadcn/ui** 元件與 hook API，以 **Storybook**／Fumadocs／MDX 提供用法文件與範例，並在客戶應用採用以去掉重複 UI；以 **Vitest** 與 **Playwright**／**Cypress** 作為共享 UI 及其消費流程的品質關卡。
- 在所有客戶 Web／流動應用及其 API 上運行 **Sentry**，讓生產崩潰、裝置問題與 API 錯誤在上線後可見。
- 主導採用 **tRPC** 與 Scalar docs，將 API 整合時間縮短 **50%**，並消除 schema 不符錯誤，讓產品工作不被契約漂移卡住。
- 以 headless CMS（Strapi／Sanity）與統一搜尋（Meilisearch／Algolia）在 **Next.js** 上取代各客戶站點的 WordPress：載入時間縮短 **80%**、搜尋延遲降低 **90%**，PageSpeed Insights **>95**。
- 透過結對編程、程式碼審查與共同交付正式 UI，指導暑期實習生與初級開發者。
