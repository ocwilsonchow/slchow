- 透過結對編程、程式碼審查與共同交付正式上線工作，指導暑期實習生與初級開發者。

### 高效能行銷網站，2025 年 11 月

- Next.js + Strapi + Meilisearch，**Core Web Vitals**——**LCP &lt; 0.5s**、**CLS &lt; 0.1**，PageSpeed Insights **>90**。

- 以 TanStack Query prefetch／hydration、TanStack Form + Zod 與 XState 建構互動與多步流程；客戶內容站點支援 locale-aware 路由、文案與日期／數字格式。
