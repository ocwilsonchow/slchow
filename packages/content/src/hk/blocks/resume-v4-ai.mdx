## 精選專案

### 多渠道 Agent 平台，2026 年 4 月至今

面向客戶的持久化助手平台（Web + Discord），具備生產級可靠性與品質控制。

- 選擇持久化串流而非 request／response 聊天，使長 tool loops 能在斷線後存活；客戶端可在執行途中恢復而不遺失進度。
- 基於 Mastra 與 AI SDK 建構 workflow、memory、scheduling 和 workspace 原語：pause／resume、retries、檔案儲存、沙盒工具與 skills。
- 端到端交付 RAG：ingest／parse、chunking，以及 Pinecone retrieval（query／rerank，必要時 graph query）。檢索按**組織隔離**（namespace = organization），模型無法搜尋其他租戶。
- 在 ClickHouse 中加入 run／tool traces 與成本／延遲指標；prompt 或 tool 變更後以帶評分的 evals 作為發布門控——問題診斷覆蓋 UI、API 與 agent runs。
- 將 **容器化**的 Hono + Better Auth 運行於 **ECS Fargate**，Postgres 存核心資料、S3 存檔案——使 agent 狀態與產物跨過單次請求繼續存在。
- 交付 TipTap @mention 檔案標記元件，使 workspace 檔案作為一等上下文進入 prompts，而非貼上的文字塊。
