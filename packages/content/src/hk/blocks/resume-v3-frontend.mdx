- 將 Next.js 作為 isomorphic UI 與 BFF：SSR／ISR，聚合 Shopify GraphQL、CMS 與搜尋 API 並做快取。獨立排查 Node 執行時問題與生產瓶頸（Lighthouse、Sentry）。

- 使用 Hono、Drizzle、OpenAPI 與 tRPC 在 AWS Lambda／API Gateway 上建構型別安全 API（Postgres／DynamoDB／S3）。加固邊緣：**嚴格 CORS**、trusted origins、auth 路由的 WAF 限流，身分來自 authorizer cookie——絕不信任客戶端傳入的 user header。API keys、tokens 與憑證存放於 **SST Secret**，而非 `.env`。GitHub Actions + SST 做 CI／CD——部署前跑 lint、typecheck、tests 與 build——部署時間縮短 **50%+**。

### 高效能行銷網站，2025 年 11 月

擔任內容與搜尋型行銷網站的前端負責人——效能、CMS 頁面與發布 UX。

- Next.js + Strapi + Meilisearch，達到 **LCP &lt; 0.5s**、**CLS &lt; 0.1**，PageSpeed Insights **>90**。
- 選擇混合 ISR 而非全量 SSG 或純按需：主要頁面與最新 100 篇文章在建置時生成，其餘按需；透過 Strapi webhook 做 tag revalidation，發布後無需完整重建即可上線。
- 將無障礙與 SEO 納入交付標準：語意化結構、鍵盤可操作的導覽與表單、Lighthouse + axe；來自 CMS 的 metadata／OG、canonicals、sitemap、robots.txt 與 Article JSON-LD。
- 以 TanStack Query prefetch／hydration 與 TanStack Form + Zod 編排互動與多步流程；客戶內容站點支援 locale-aware 路由、文案與日期／數字格式。
