我是一名擁有 4 年以上經驗的軟件開發者，專注於構建高效能、可靠的應用程式，同時也是認證的 AWS Solutions Architect Associate。

我主導過用戶介面的 [Figma 設計](/writings/figma-design)，以及應用前端與設計系統的開發。

Typescript 是我的主要編程語言。前端方面，我主要使用 React 與 Next.js，以及 React Native 與 Expo。後端方面，我使用 Hono、Drizzle、OpenAPI 與 RPC 構建 API，並用 Strapi 和 Sanity 做無頭 CMS 整合。雲基礎設施方面，我首選在 AWS 上使用 SST。

過去一年，我一直在構建 RAG、agents 與自動化，主要使用 Mastra，也嘗試過 Langchain、ai-sdk 和 strands。
