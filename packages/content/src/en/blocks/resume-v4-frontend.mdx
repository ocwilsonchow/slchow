### React Native Membership Platform, shipped Apr 2024

- Owned membership flows (digital card, points, offers) from Figma through release on the Apple App Store and Google Play; also owned the **Next.js** admin.
- Mitigated session risk by storing refresh tokens in **SecureStore** / Keychain and requiring Face ID / fingerprint to unlock the session; generated typed **REST** clients from **OpenAPI**.
- Maintained **99%** crash-free sessions after launch by diagnosing crashes, device compatibility issues, and API bottlenecks with **Sentry**.
