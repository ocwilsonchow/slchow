我是一名拥有 4 年以上经验的软件开发者，专注于构建高性能、可靠的应用，同时也是认证的 AWS Solutions Architect Associate。

我主导过用户界面的 [Figma 设计](/writings/figma-design)，以及应用前端与设计系统的开发。

Typescript 是我的主要编程语言。前端方面，我主要使用 React 与 Next.js，以及 React Native 与 Expo。后端方面，我使用 Hono、Drizzle、OpenAPI 与 RPC 构建 API，并用 Strapi 和 Sanity 做无头 CMS 集成。云基础设施方面，我首选在 AWS 上使用 SST。

过去一年，我一直在构建 RAG、agents 与自动化，主要使用 Mastra，也尝试过 Langchain、ai-sdk 和 strands。
