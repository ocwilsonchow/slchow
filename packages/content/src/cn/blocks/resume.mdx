- 使用 **TipTap** 设计并交付自定义 **@mention** 文件标记组件，用于 agent 提示输入。

---

### _Incremental Static Regeneration Next.js Site，2025 年 11 月_

- 打造 **Next.js** 内容站点，后端为 **Strapi**、搜索为 **Meilisearch**，达到 **LCP < 0.5s**、**CLS < 0.1**，PageSpeed Insights **>90**。
- 混合式 **ISR**：主要页面与最新 100 篇文章在构建时预渲染；其余页面按需以 fallback 生成。
- 通过 Strapi 内容 webhook 进行 **tag-based revalidation**，发布后可更新线上页面而无需完整重建。
- 交互 UI 使用 **TanStack Query** 服务端 prefetch／hydration；表单以 **TanStack Form**、**Zod** 与 Query mutations 处理。
- **Turborepo** 通过 **SST** 部署至 **AWS ECS**，经 **API Gateway** 路由；媒体存放于 **S3**。
- **无障碍（Accessibility）**：语义化 landmarks／标题、键盘可操作的导航与表单、可见 focus，以及 CMS 媒体的有意义 alt text。
- **SEO**：来自 Strapi 的 metadata／OG tags、canonical URLs、sitemap + `robots.txt`，以及 Article JSON-LD 结构化数据，提升内容页可索引性。
