## 精选项目

### 多渠道 Agent 平台，2026 年 4 月至今

面向客户的持久化助手平台（Web + Discord），具备生产级可靠性与质量控制。

- 选择持久化串流而非 request／response 聊天，使长 tool loops 能在断线后存活；客户端可在执行途中恢复而不丢失进度。
- 基于 Mastra 与 AI SDK 构建 workflow、memory、scheduling 和 workspace 原语：pause／resume、retries、文件存储、沙箱工具与 skills。
- 端到端交付 RAG：ingest／parse、chunking，以及 Pinecone retrieval（query／rerank，必要时 graph query）。
- 在 ClickHouse 中加入 run／tool traces 与成本／延迟指标；prompt 或 tool 变更后以带评分的 evals 作为发布门控。
- 在 ECS 上运行 Hono + Better Auth，Postgres 存核心数据、S3 存文件——使 agent 状态与产物跨过单次请求继续存在。
- 交付 TipTap @mention 文件标记组件，使 workspace 文件作为一等上下文进入 prompts，而非粘贴的文本块。
