### 高性能营销网站，2025 年 11 月

担任内容与搜索型营销网站的前端负责人——性能、CMS 页面与发布 UX。

- Next.js + Strapi + Meilisearch，达到 **LCP &lt; 0.5s**、**CLS &lt; 0.1**，PageSpeed Insights **>90**。
- 选择混合 ISR 而非全量 SSG 或纯按需：主要页面与最新 100 篇文章在构建时生成，其余按需；通过 Strapi webhook 做 tag revalidation，发布后无需完整重建即可上线。
- 将无障碍与 SEO 纳入交付标准：语义化结构、键盘可操作的导航与表单、Lighthouse + axe；来自 CMS 的 metadata／OG、canonicals、sitemap、robots.txt 与 Article JSON-LD。
- 以 TanStack Query prefetch／hydration 与 TanStack Form + Zod 编排交互与多步流程；客户内容站点支持 locale-aware 路由、文案与日期／数字格式。
